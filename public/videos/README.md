# Video Hero - Paneles Solares

## Ubicación
public/videos/solar-hero.mp4

## Instrucciones
Necesitas descargar un video de paneles solares desde Pixabay y guardarlo como solar-hero.mp4 en esta carpeta.

### Recursos sugeridos:
- https://pixabay.com/videos/search/solar%20panels/
- https://pixabay.com/videos/search/solar%20farm/
- https://pixabay.com/videos/search/renewable%20energy/

### Recomendaciones:
- Busca tomas aéreas de paneles solares en cubiertas comerciales o parques solares
- Movimiento cinematográfico suave
- Resolución adecuada para web (720p o 1080p)
- Duración corta (10-30 segundos, loop)

### Licencia
Verifica siempre la licencia del video seleccionado en Pixabay antes de usarlo.

### Poster
También necesitas crear public/images/solar-hero-poster.webp como imagen de respaldo.
